# Backend Data Schema & Data Structures (BACKEND_SCHEMA)

## 1. Database Configuration
- **Database Engine**: MongoDB
- **ODM (Object Data Modeling)**: Mongoose 9.9.4
- **Database Name**: `aikms` (Default connection string: `mongodb://127.0.0.1:27017/aikms`)
- **Schema Features**: Mongoose strict schema enforcement, automatic timestamping (`createdAt`, `updatedAt`), pre-save middleware hooks, and method instances.

### 2.1 User Collection (`users`)

**File Location**: [user.model.js](file:///c:/Users/mohd%20affan/major-projects/ai-kms/Backend/src/models/user.model.js)

#### Schema Definition & Fields:
| Field Name | Data Type | Required | Unique | Default Value | Validation / Constraints | Description |
|---|---|---|---|---|---|---|
| `_id` | ObjectId | Auto | Yes | Auto ObjectId | Generated by MongoDB | Unique primary user identifier |
| `name` | String | Yes | No | None | `trim: true` | User's full display name |
| `email` | String | Yes | Yes | None | `lowercase: true`, `trim: true`, Regex validation (`^\w+([\.-]?\w+)*@\w+([\.-]?\w+)*(\.\w{2,3})+$`) | Primary login email address |
| `password` | String | Yes | No | None | `minlength: 8` | Bcrypt hashed password string |
| `profileImage` | String | No | No | `'https://images.unsplash.com/...'` | String URL | Profile picture avatar URL |
| `role` | String | No | No | `'student'` | Enum: `['student', 'teacher', 'admin']` | User access role |
| `createdAt` | Date | Auto | No | Current timestamp | Managed by Mongoose `{ timestamps: true }` | Account creation timestamp |
| `updatedAt` | Date | Auto | No | Current timestamp | Managed by Mongoose `{ timestamps: true }` | Account last updated timestamp |

#### Hooks & Instance Methods:
- **`userSchema.pre('save')`**: Pre-save hook checking `if (!this.isModified('password')) return;`. Automatically generates a 10-round salt using `bcrypt.genSalt(10)` and hashes the password string before storing in database.
- **`userSchema.methods.matchPassword(enteredPassword)`**: Instance method executing `bcrypt.compare(enteredPassword, this.password)` returning a boolean promise.

## 3. Database Relationships

```
+--------------------------------+           1 : N           +----------------------------------+
|           User Model           | ------------------------> |          Document Model          |
|--------------------------------|                           |----------------------------------|
| _id: ObjectId                  |                           | _id: ObjectId                    |
| name: String                   |                           | title: String                    |
| email: String (Unique)         |                           | contentType: "file" | "note"     |
| password: String (Hashed)      |                           | uploadedBy: Ref("User") <======  |
| role: "student"|"teacher"|"admin"                          | processingStatus: String         |
+--------------------------------+                           +----------------------------------+
```

- **User to Documents (1:N)**: One User can own multiple Documents.
- **Reference Binding**: `Document.uploadedBy` holds the `mongoose.Schema.Types.ObjectId` referencing `User._id`.
- **Authorization Enforcement**: Controllers verify ownership before accessing or deleting documents (`document.uploadedBy.toString() === req.user._id.toString()`).

## 4. Middleware & Utility Structures

### 4.1 Disk Storage Multer Configuration ([uploadMiddleware.js](file:///c:/Users/mohd%20affan/major-projects/ai-kms/Backend/src/middleware/uploadMiddleware.js))
- **Destination Folder**: `uploads/`
- **Naming Standard**: `${Date.now()}-${Math.round(Math.random() * 1e9)}${extension}`
- **Size Cap**: `20 * 1024 * 1024` bytes (20MB max file size limit).
- **MIME & Extension Whitelist**:
  - `application/pdf` (`.pdf`)
  - `application/vnd.ms-powerpoint`, `application/vnd.openxmlformats-officedocument.presentationml.presentation` (`.ppt`, `.pptx`)
  - `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document` (`.doc`, `.docx`)
  - `text/plain` (`.txt`)
  - `text/markdown`, `text/x-markdown` (`.md`)

### 4.2 Auth Middleware Payload ([authMiddleware.js](file:///c:/Users/mohd%20affan/major-projects/ai-kms/Backend/src/middleware/authMiddleware.js))
- **Extracted Header**: `Authorization: Bearer <token>`
- **Decoded Payload**: `{ id: user._id, iat: number, exp: number }`
- **Attached Express Object**: `req.user` populated via `User.findById(decoded.id).select('-password')`.

## 5. Endpoints & Data Operations Summary

| Operation | Controller Function | Database Query Executed | Data Output |
|---|---|---|---|
| Register User | `registerUser` | `User.findOne({ email })`, `User.create(...)` | User profile JSON + JWT Token |
| Login User | `loginUser` | `User.findOne({ email })` + `user.matchPassword()` | User profile JSON + JWT Token |
| Get User Profile | `getUserProfile` | `User.findById(req.user._id).select('-password')` | Logged-in User profile JSON |
| Update Profile | `updateUserProfile` | `User.findById(...)`, `user.save()` | Updated User profile JSON |
| Change Password | `changeUserPassword` | `User.findById(...)`, `user.save()` | Success message JSON |
| Upload Document | `uploadDocument` | `Document.create(...)` | Created Document JSON |
| Get My Documents | `getMyDocuments` | `Document.find({ uploadedBy, ...filters }).sort({ createdAt: -1 })` | Array of Document JSON objects |
| Delete Document | `deleteDocument` | `Document.findById(id)`, `Document.findByIdAndDelete(id)` | Success message JSON |
