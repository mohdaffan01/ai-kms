# Backend Data Schema & Data Structures (BACKEND_SCHEMA)

## 1. Database Configuration
- **Database Engine**: MongoDB
- **ODM (Object Data Modeling)**: Mongoose 9.9.4
- **Database Name**: `aikms` (Default connection string: `mongodb://127.0.0.1:27017/aikms`)
- **Schema Features**: Mongoose strict schema enforcement, automatic timestamping (`createdAt`, `updatedAt`), pre-save middleware hooks, and method instances.

### 2.1 User Collection (`users`)

**File Location**: [user.model.js](file:///c:/Users/mohd%20affan/major-projects/ai-kms/Backend/src/models/user.model.js)

#### Schema Definition & Fields:
| Field Name | Data Type | Required | Unique | Default Value | Validation / Constraints | Description |
|---|---|---|---|---|---|---|
| `_id` | ObjectId | Auto | Yes | Auto ObjectId | Generated by MongoDB | Unique primary user identifier |
| `name` | String | Yes | No | None | `trim: true` | User's full display name |
| `email` | String | Yes | Yes | None | `lowercase: true`, `trim: true`, Regex validation (`^\w+([\.-]?\w+)*@\w+([\.-]?\w+)*(\.\w{2,3})+$`) | Primary login email address |
| `password` | String | Yes | No | None | `minlength: 8` | Bcrypt hashed password string |
| `role` | String | No | No | `'student'` | Enum: `['student', 'teacher', 'admin']` | User access role |
| `resetPasswordToken` | String | No | No | `undefined` | Hashed token string | Password reset security token |
| `resetPasswordExpire` | Date | No | No | `undefined` | Date object | Password reset token expiration timestamp (30 mins) |
| `resetPasswordOtp` | String | No | No | `undefined` | Numeric OTP string | Optional OTP code for password reset |
| `resetPasswordOtpExpire` | Date | No | No | `undefined` | Date object | OTP expiration timestamp |
| `createdAt` | Date | Auto | No | Current timestamp | Managed by Mongoose `{ timestamps: true }` | Account creation timestamp |
| `updatedAt` | Date | Auto | No | Current timestamp | Managed by Mongoose `{ timestamps: true }` | Account last updated timestamp |

#### Hooks & Instance Methods:
- **`userSchema.pre('save')`**: Pre-save hook checking `if (!this.isModified('password')) return;`. Automatically generates a 10-round salt using `bcrypt.genSalt(10)` and hashes the password string before storing in database.
- **`userSchema.methods.matchPassword(enteredPassword)`**: Instance method executing `bcrypt.compare(enteredPassword, this.password)` returning a boolean promise.

### 2.3 Progress Collection (`progress`)

**File Location**: [progress.model.js](file:///c:/Users/mohd%20affan/major-projects/ai-kms/Backend/src/models/progress.model.js)

Tracks learning progress, subject cards, hierarchical topic and subtopic completion status, and real-time study activity logs.

#### Root Schema Fields:
| Field Name | Data Type | Required | Unique | Default Value | Description |
|---|---|---|---|---|---|
| `_id` | ObjectId | Auto | Yes | Auto ObjectId | Unique primary progress document identifier |
| `userId` | ObjectId | Yes | Yes | None | Foreign key ref to `User._id` (indexed & unique) |
| `subjects` | Array<Subject> | No | No | `[]` | List of subject objects with hierarchical topics (dynamically generated from uploaded materials or user creation) |
| `recentActivities` | Array<Activity> | No | No | `[]` | List of recent learning & upload activity events |
| `createdAt` | Date | Auto | No | Current timestamp | Creation timestamp |
| `updatedAt` | Date | Auto | No | Current timestamp | Last updated timestamp |

#### Subdocument Schemas:

1. **Subtopic Schema (`subtopicSchema`)**:
   - `id`: String (Unique subtopic identifier, e.g. `subtop-dbms-1-1`)
   - `name`: String (Required, trimmed, e.g. `Key Features of DBMS`)
   - `completed`: Boolean (Default: `false`)
   - `completedAt`: Date (Default: `null`)

2. **Topic / Chapter Schema (`topicSchema`)**:
   - `id`: String (Unique parent topic identifier, e.g. `top-dbms-1`)
   - `name`: String (Required, trimmed, e.g. `1. All about DBMS`)
   - `completed`: Boolean (Default: `false`)
   - `completedAt`: Date (Default: `null`)
   - `isExtracted`: Boolean (Default: `false`, true when parsed from uploaded documents)
   - `isUserCreated`: Boolean (Default: `false`, true when manually added by user)
   - `subtopics`: Array of `subtopicSchema` (Hierarchical child topics nested under this chapter)

3. **Subject Schema (`subjectSchema`)**:
   - `id`: String (Unique subject identifier, e.g. `dbms`, `os`, `sub-custom-...`)
   - `name`: String (Required, trimmed, e.g. `Database Management Systems`)
   - `code`: String (Optional, e.g. `CS-301`)
   - `description`: String (Subject summary description)
   - `category`: String (Default: `'Computer Science'`)
   - `icon`: String (Default: `'Database'`, `'BookOpen'`, etc.)
   - `color`: String (Hex color code, e.g. `'#10a37f'`)
   - `topics`: Array of `topicSchema`
   - `createdAt`: Date (Default: `Date.now`)

4. **Recent Activity Schema (`activitySchema`)**:
   - `id`: String (Unique activity event ID)
   - `type`: String (Enum: `'topic_completed'`, `'topic_uncompleted'`, `'subject_created'`, `'doc_uploaded'`, `'study_session'`)
   - `title`: String (Human-readable description)
   - `subject`: String (Subject name associated)
   - `timestamp`: Date (Default: `Date.now`)

## 3. Database Relationships

```
+--------------------------------+           1 : N           +----------------------------------+
|           User Model           | ------------------------> |          Document Model          |
|--------------------------------|                           |----------------------------------|
| _id: ObjectId                  |                           | _id: ObjectId                    |
| name: String                   |                           | title: String                    |
| email: String (Unique)         |                           | contentType: "file" | "note"     |
| password: String (Hashed)      |                           | uploadedBy: Ref("User") <======  |
| role: "student"|"teacher"|"admin"                          | processingStatus: String         |
+--------------------------------+                           +----------------------------------+
        │                 │
  1 : 1 │                 │ 1 : N
        v                 v
+-----------------------+ +-----------------------------------------------------+
|    Progress Model     | |                   Flashcard Model                   |
|-----------------------| |-----------------------------------------------------|
| _id: ObjectId         | | _id: ObjectId                                       |
| userId: Ref("User")   | | userId: Ref("User") (Compound Index)                |
| subjects: [ topics ]  | | subject, topic, front, back, hint, difficulty       |
| recentActivities: [ ] | | isMastered: Boolean, reviewCount, source            |
+-----------------------+ +-----------------------------------------------------+
```

- **User to Documents (1:N)**: One User can own multiple Documents.
- **User to Flashcards (1:N)**: One User owns study flashcards organized by subject and topic.
- **User to Progress (1:1)**: Each User has one unified Progress tracking record storing subject learning states and extracted topic hierarchies.
- **Document to Progress Synchronization**: When a document is uploaded, `extractTopicsFromDocument` automatically updates `Progress.subjects` with extracted parent chapters and child subtopics.
- **Progress to Flashcards Generation**: Flashcard AI generation inspects `Progress.subjects.topics` for `completed: true` entries to automatically generate targeted revision decks.

## 4. Middleware & Utility Structures

### 4.1 Disk Storage Multer Configuration ([uploadMiddleware.js](file:///c:/Users/mohd%20affan/major-projects/ai-kms/Backend/src/middleware/uploadMiddleware.js))
- **Destination Folder**: `uploads/`
- **Naming Standard**: `${Date.now()}-${Math.round(Math.random() * 1e9)}${extension}`
- **Size Cap**: `20 * 1024 * 1024` bytes (20MB max file size limit).
- **MIME & Extension Whitelist**:
  - `application/pdf` (`.pdf`)
  - `application/vnd.ms-powerpoint`, `application/vnd.openxmlformats-officedocument.presentationml.presentation` (`.ppt`, `.pptx`)
  - `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document` (`.doc`, `.docx`)
  - `text/plain` (`.txt`)
  - `text/markdown`, `text/x-markdown` (`.md`)

### 4.2 Auth Middleware Payload ([authMiddleware.js](file:///c:/Users/mohd%20affan/major-projects/ai-kms/Backend/src/middleware/authMiddleware.js))
- **Extracted Header**: `Authorization: Bearer <token>`
- **Decoded Payload**: `{ id: user._id, iat: number, exp: number }`
- **Attached Express Object**: `req.user` populated via `User.findById(decoded.id).select('-password')`.
